* **주가 변동 폭**: 시초 저점 28,500원(+2.33%) → 당일 최고점 32,600원(+17.06%)

* **단위 체결 통제 기준**: 1회 시장가 매수 상한선을 약 1,000주(주당 3만 원 기준 약 3,000만 원 내외)로 철저히 캡(Cap) 적용

### 2. 거시 파동(Macro Waves) 및 단계별 전개 구조

```text
[Wave 1: 베이스캠프 구축] 09:02 ~ 09:13
  28,500원(+2.33%) ──► 30,750원(+10.41%)
  · 29,850원(+975주), 30,500원(+1,036주) 등 마디가 벽 소각

[Wave 2: 메인 랠리 & 고점 갱신] 09:39 ~ 09:51
  31,100원(+11.67%) ──► 32,600원(+17.06%) ★ 당일 주도 파동
  · 31,250원(+1,007주), 32,450원(+1,017주) 돌파 및 연쇄 단주 체결

[Wave 3: 하방 방어 및 락인] 10:19 ~ 12:58
  31,450원 ~ 31,650원(+13%대 지지)
  · 투매(-2,305주 등) 흡수 및 소액 지속 체결로 저점 고정

```

* **1단계 (Round-number 소각)**: 30,000원, 30,500원, 31,250원, 32,450원 등 상징적 저항 매도벽에 도달하면 900~1,000주 안팎의 일시 시장가 블록(Block Sweep)으로 소진시킵니다.
* **2단계 (호가 공백 전진 - Ping Drive)**: 대량 매도벽이 뚫린 직후 얇아진 상위 2~4개 호가를 1초 이내에 1~10주 단위의 단주로 싹쓸이하여 최유리 호가를 강제로 레벨업시킵니다.
* **3단계 (시간차 숨고르기 - Time Slicing)**: 10~15분간 급등을 유도한 뒤, 20~25분 동안 매수를 전면 중단하여 시장 자율 조정과 거래량 분모 확대를 유도합니다.
* **4단계 (바닥 지지선 락인 - Floor Pegging)**: 차익실현 매도가 쏟아질 때 특정 마디가(31,500원~31,600원)에서 10~30주 단위로 하단 호가를 촘촘히 체결시켜 하방 이탈을 차단합니다.

### 4. 실시간 매매 대응 프레임워크 (Trading Rule)

#### 진입 조건 (Entry Trigger)

1. **횡보 조건**: 최소 15분 이상 거래량이 급감하며 좁은 박스권(변동폭 1% 이내) 횡보 유지.
2. **신호 포착**: 직전 고점 또는 라운드피겨 호가에 누적된 매도 잔량이 **1초 이내에 500~1,000주 단일 블록으로 소진**.
3. **추종 확인**: 블록 체결 직후 상위 호가로 1~10주 단위 매수 체결이 연속 3회 이상 상향 갱신될 때 시장가/최유리 매수로 동반 진입.

#### 청산 조건 (Exit Trigger)

1. **목표 익절**: 1차 파동 진입 후 **+1.5% ~ +2.0% 구간**에서 분할 익절 (주포의 단일 파동 마진 한계).
2. **추세 이탈 손절**: 상승 시작점의 기준 호가(예: 31,500원) 아래로 호가를 2~3단계 건너뛰는 수백 주 단위 시장가 투매(-체결)가 연속 2회 찍힐 경우 즉시 전량 손절.

### 5. 실시간 모니터링 수식 및 알고리즘 조건 (파이썬 예시)

```python
def check_smart_money_entry(ticks_1sec):
    """
    1초(1,000ms) 동안 수집된 체결 틱 데이터 분석
    """
    total_buy_vol = sum(tick.vol for tick in ticks_1sec if tick.side == "BUY")
    max_single_buy = max([tick.vol for tick in ticks_1sec if tick.side == "BUY"], default=0)
    price_spread = max(tick.price for tick in ticks_1sec) - min(tick.price for tick in ticks_1sec)
    
    # 1. 1초 내 단일 500주 이상 또는 합산 800주 이상 블록 매수 발생
    is_block_sweep = (max_single_buy >= 500) or (total_buy_vol >= 800)
    
    # 2. 1회 주문 크기가 1,200주(감시 기준선)를 초과하지 않고 분할된 형태
    is_controlled_size = max_single_buy <= 1200
    
    # 3. 호가를 위로 2호가 이상 들어 올렸는지 확인
    is_price_driving = price_spread >= (tick.tick_size * 2)
    
    if is_block_sweep and is_controlled_size and is_price_driving:
        return "TRIGGER_BUY_FOLLOW_UP"
    return "WAIT"

```
